학교 지원 경로 개선 제안

AI·Google Slides 사용 안내 자세히 보기

교재의 활동 1부터 순서대로 진행하고, HTML을 열라는 안내가 나오면 같은 번호의 웹 활동으로 이동합니다. 웹에 입력 칸이 없는 도입·개념 문제는 교재에 답합니다. 웹에 작성한 답은 교재에 다시 옮기지 않습니다. 이 파일은 공동 편집 문서가 아니므로 모둠 기록 담당자 한 명의 기기에서 입력합니다. 개인 성찰은 모둠원마다 직접 작성하고, 각 답 앞에 제출 번호를 붙여 줄을 나눕니다. 모둠 기록과 개인 답을 구분하세요.

HTML 열기·작성·저장·제출 방법
  1. 교사가 배부한 단원 HTML 파일을 내려받고 Chrome 또는 Edge로 엽니다. ZIP으로 받았다면 먼저 압축을 풉니다.
  2. 활동 번호에 따라 자료를 읽고 답을 작성합니다. 외부 AI나 Slides는 링크로 새 창에서 열고, 작업 뒤 이 창으로 돌아옵니다.
  3. 중간에 이어쓰기 저장을 눌러 JSON 파일을 받습니다. 다음 시간에는 이 HTML을 다시 열고 이어쓰기 불러오기에서 JSON을 선택합니다.
  4. 끝나면 결과물 미리보기를 확인하고 제출용 문서 저장을 누릅니다. 저장된 HTML은 답안과 첨부 그림을 읽는 문서입니다.
  5. 저장한 문서를 다시 열어 내용을 확인한 뒤 교사가 지정한 과제함에 제출합니다. PDF 제출은 인쇄·PDF 저장에서 PDF 대상을 선택합니다.

입력은 자동 저장되지 않습니다. 창을 닫기 전에 저장하세요. AI 결과가 자동으로 들어오거나 교사에게 자동 제출되지는 않습니다.

교사가 안내한 활동 범위에 따라 작성합니다. 작성 누락 확인은 입력·첨부 여부를 점검하며, 답안이 옳은지를 자동으로 평가하지 않습니다.

2. 우리 학교의 실제 지원 경로 조사하기

교사가 제공한 실제 학교 안내를 우선 사용하세요. 준비된 자료가 없으면 아래 가상 안내로 연습하고, 결과물에도 가상 학교임을 표시합니다.

대체 자료 · 솔빛고 가상 안내

솔빛고 가상 안내: 학생은 담임교사에게 직접 상담을 요청하거나 학교 계정의 상담 신청 문서에 글로 신청할 수 있습니다. 담당 상담교사는 접수 후 학교 계정으로 일정을 안내합니다. AI 상담은 선택 사항입니다. AI 요약 기록의 정정 접수처와, AI 이용 도중 담당자에게 연결하는 방법은 안내에 제시되어 있지 않습니다. 이 자료는 연습용이며 실제 학교의 제도·연락처·운영시간을 뜻하지 않습니다.

5. 학교 지원 경로 개선안 만들기

전체 활동은 네 경로, 50분 축약 활동은 위에서 선택한 한 경로의 개선안으로 포스터를 만듭니다. 현재 안내된 사실과 새로 제안하는 방법을 구분하고 제목에 학생 개선 제안임을 표시하세요.

Gemini 접속·입력·응답 기록 방법
  1. Gemini 열기를 누르고 학교에서 허용한 Google 계정으로 로그인합니다. 오른쪽 위 계정 표시를 확인합니다.
  2. 왼쪽 메뉴에서 새 채팅을 엽니다. 메뉴가 접혀 있으면 먼저 메뉴 버튼을 누릅니다.
  3. 이 활동지의 요청문을 복사하여 Gemini 입력창에 붙여 넣습니다. 대괄호나 빈칸이 남아 있으면 활동에서 정한 내용으로 채웁니다.
  4. 응답을 받은 뒤, 원문 자료와 대조합니다. AI가 제시한 말이라는 이유만으로 근거로 인정하지 않습니다.
  5. 활동지로 돌아와 실제 응답과 도구명·사용 날짜를 남깁니다. 접속할 수 없으면 교사가 제공한 실제 응답을 사용하고 제공 자료임을 표시합니다.

Google 계정이 있어도 학교 설정과 연령에 따라 기능이 다를 수 있습니다. 로그인·이용 제한은 교사에게 확인하며, 수업은 유료 결제 없이 진행합니다.

Gemini 공식 사용 안내
Google Slides 접속·공동 작성·그림 저장 방법
  1. 새 Google 프레젠테이션 열기를 누르고 Google 계정으로 로그인합니다. 왼쪽 위 제목을 눌러 단원번호_모둠번호_활동명으로 바꿉니다.
  2. 슬라이드 → 레이아웃 적용 → 빈 슬라이드를 선택합니다. 도형·글상자가 필요한 활동에서는 기본 제목 상자를 지우고 시작해도 됩니다.
  3. 삽입 → 도형 → 도형 → 사각형을 선택하고 빈 슬라이드에서 드래그하여 상자를 만듭니다. 도형을 두 번 클릭해 학생·학교 등 이름을 입력합니다. 가장자리를 드래그하면 크기를, 도형을 잡아 끌면 위치를 바꿀 수 있습니다.
  4. 삽입 → 텍스트 상자를 선택해 설명을 넣을 곳에 드래그한 뒤 문구를 입력합니다. 삽입 → 선 → 화살표를 선택하고 출발 도형에서 도착 도형 쪽으로 드래그합니다. 화살표 옆에는 별도 텍스트 상자로 이동하는 정보의 이름을 적습니다.
  5. 수정 전후를 비교할 때는 왼쪽의 슬라이드 미리보기를 오른쪽 클릭해 슬라이드 복제를 선택합니다. 원본은 남기고 복사본을 고칩니다.
  6. 모둠원이 함께 편집할 때는 공유에서 모둠원의 계정을 추가하고 편집 권한을 부여합니다. 교사에게 링크로 제출할 경우 교사가 안내한 계정에 보기 권한을 부여합니다.
  7. 그림으로 저장하려는 슬라이드를 선택하고 파일 → 다운로드 → PNG 이미지를 선택합니다. PNG는 선택한 한 슬라이드만 저장하므로 수정 전후를 각각 저장합니다.
  8. 문서 전체를 제출할 때는 파일 → 다운로드 → PDF 문서를 사용합니다. 이 웹에 그림을 첨부하라는 활동은 PNG·JPG로 저장한 뒤 해당 파일 선택 칸에서 첨부합니다.

웹 활동지에는 Slides의 편집 내용이 자동으로 들어오지 않습니다. 이미지 첨부나 교사가 열 수 있는 링크를 별도로 남겨야 합니다. 메뉴 이름이 다르면 상단 메뉴 검색에서 도형·복제·다운로드를 찾습니다.

AI 문구를 Slides 포스터로 옮기기
  1. 위 요청문을 Gemini 새 대화에 붙여 넣고 문구와 배치 제안을 받습니다.
  2. AI가 만든 연락처·시간·제도가 있는지 학교 자료와 대조해 고칩니다. 원래 조사 내용과 비교한 뒤 사용할 문구를 정합니다.
  3. 새 Google Slides에서 제목과 지원 경로 구역을 만듭니다. 전체 활동은 네 구역, 50분 축약 활동은 선택한 경로 한 구역입니다. 각 구역에 담당자·요청 방법·후속 안내를 배치하고, 확인되지 않은 내용은 제안 또는 확인 필요로 표시합니다.
  4. 제목에 학생 개선 제안을 표시합니다. 가상 자료라면 솔빛고 가상 사례·학생 개선 제안으로 표시하고, 확인된 안내에는 출처를 적습니다.
  5. 완성본을 PNG로 저장해 아래에 첨부합니다. 다음 활동에서 고치면 최종 이미지로 다시 첨부합니다.

6. 돌아보기

다른 모둠의 실제 사용 검토를 기록합니다. AI 검토를 하지 못했다면 이유를 남기고 동료 검토를 진행하세요. 검토 의견은 있는 만큼만 작성하며, 수정할 필요가 없다면 유지한 근거를 설명합니다.

이 포스터에서 학생이 도움을 요청하는 데 필요한 정보가 빠졌거나 불분명한 부분을 찾아 주세요. 해당 문구와 이유를 제시하고, 근거 없이 문제 수를 채우지는 마세요.

Gemini에 포스터 이미지를 첨부할 수 없으면 문구와 배치를 텍스트로 제공합니다. 다른 모둠에게도 포스터만 보고 한 상황의 요청 방법을 찾도록 하세요. AI 접속이 안 되면 그 사실을 기록하고 동료 검토를 진행합니다. 수정할 필요가 없다는 의견도 확인 근거를 남기면 됩니다.
