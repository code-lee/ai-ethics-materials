저작권 점검표 만들기

AI·Google Slides 사용 안내 자세히 보기

교재의 활동 1부터 순서대로 진행하고, HTML을 열라는 안내가 나오면 같은 번호의 웹 활동으로 이동합니다. 웹에 입력 칸이 없는 도입·개념 문제는 교재에 답합니다. 웹에 작성한 답은 교재에 다시 옮기지 않습니다. 이 파일은 공동 편집 문서가 아니므로 모둠 기록 담당자 한 명의 기기에서 입력합니다. 개인 성찰은 모둠원마다 직접 작성하고, 각 답 앞에 제출 번호를 붙여 줄을 나눕니다. 모둠 기록과 개인 답을 구분하세요.

HTML 열기·작성·저장·제출 방법
  1. 교사가 배부한 단원 HTML 파일을 내려받고 Chrome 또는 Edge로 엽니다. ZIP으로 받았다면 먼저 압축을 풉니다.
  2. 활동 번호에 따라 자료를 읽고 답을 작성합니다. 외부 AI나 Slides는 링크로 새 창에서 열고, 작업 뒤 이 창으로 돌아옵니다.
  3. 중간에 이어쓰기 저장을 눌러 JSON 파일을 받습니다. 다음 시간에는 이 HTML을 다시 열고 이어쓰기 불러오기에서 JSON을 선택합니다.
  4. 끝나면 결과물 미리보기를 확인하고 제출용 문서 저장을 누릅니다. 저장된 HTML은 답안과 첨부 그림을 읽는 문서입니다.
  5. 저장한 문서를 다시 열어 내용을 확인한 뒤 교사가 지정한 과제함에 제출합니다. PDF 제출은 인쇄·PDF 저장에서 PDF 대상을 선택합니다.

입력은 자동 저장되지 않습니다. 창을 닫기 전에 저장하세요. AI 결과가 자동으로 들어오거나 교사에게 자동 제출되지는 않습니다.

교사가 안내한 활동 범위에 따라 작성합니다. 작성 누락 확인은 입력·첨부 여부를 점검하며, 답안이 옳은지를 자동으로 평가하지 않습니다.

3. 사례로 저작권 문제 분석하기

세 사례 중 하나를 선택하고, 어떤 자료를 어떤 방식으로 이용했는지 분석하세요. 법 위반 여부를 단정하기보다 확인해야 할 권리와 조건을 설명합니다.

사례 1

이미지 생성형 AI에 '뽀로로가 우리 학교 축제에서 춤추는 모습을 그려줘'라는 프롬프트를 입력하여 원작과 매우 닮은 이미지를 생성한 뒤, 이를 그대로 학교 축제 홍보 포스터 시안으로 만들어 교내 게시판과 학교 SNS 계정에 게시함.

사례 2

국어 수행평가 과제를 위해 인기 웹툰의 등장인물·배경·주요 사건 전개를 프롬프트에 상세히 입력한 뒤 AI에게 결말만 다르게 이어서 써 달라고 요청함. 이 후 생성된 글을 별도 표시 없이 자신이 직접 창작한 것처럼 과제로 제출함.

사례 3

축제에 노래를 부르기 위해 아이유의 목소리를 학습시킨 AI 커버 생성 서비스에 다른 가수 비비의 노래 음원과 가사를 그대로 입력하여 음원을 만든 뒤, 이를 학예회 발표 영상의 배경음악으로 사용하고 학교 유튜브 채널에 업로드함

조사 방법

  2. 네 조건의 뜻을 한 문장씩 정리합니다.
  3. 아래 연습 계획을 조건과 연결하여 판단합니다.
  4. 공식 자료 제목·주소를 기록합니다.

조건 적용 연습

A~D는 라이선스 조건을 판단하기 위해 만든 가상 자료입니다. 실제 배경·음악 파일이나 사례 속 캐릭터의 이용 허락을 제공하는 자료가 아닙니다.

연습 A: 가상 작가가 CC BY 4.0으로 제공한 배경 그림을 편집해 학교 SNS 포스터에 넣으려 합니다. 무엇을 표시해야 하나요?

연습 B: CC BY-NC 4.0 음악을 학교 굿즈 판매 광고에 넣으려 합니다. 학교가 쓴다는 이유만으로 비영리라고 판단할 수 있나요?

연습 C: CC BY-ND 4.0 그림의 인물 표정과 배경을 바꿔 공개하려 합니다. 단순 파일 형식 변경이 아닌 변형 결과물의 공유가 허용되나요?

연습 D: CC BY-SA 4.0 그림을 변형하여 공개하려 합니다. 변경한 그림에 어떤 라이선스 조건을 적용해야 하나요?
