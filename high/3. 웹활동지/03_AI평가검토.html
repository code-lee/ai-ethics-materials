교재의 활동 1부터 순서대로 진행하고, HTML을 열라는 안내가 나오면 같은 번호의 웹 활동으로 이동합니다. 웹에 입력 칸이 없는 도입·개념 문제는 교재에 답합니다. 웹에 작성한 답은 교재에 다시 옮기지 않습니다. 이 파일은 공동 편집 문서가 아니므로 모둠 기록 담당자 한 명의 기기에서 입력합니다. 개인 성찰은 모둠원마다 직접 작성하고, 각 답 앞에 제출 번호를 붙여 줄을 나눕니다. 모둠 기록과 개인 답을 구분하세요.

HTML 열기·작성·저장·제출 방법
  1. 교사가 배부한 단원 HTML 파일을 내려받고 Chrome 또는 Edge로 엽니다. ZIP으로 받았다면 먼저 압축을 풉니다.
  2. 활동 번호에 따라 자료를 읽고 답을 작성합니다. 외부 AI나 Slides는 링크로 새 창에서 열고, 작업 뒤 이 창으로 돌아옵니다.
  3. 중간에 이어쓰기 저장을 눌러 JSON 파일을 받습니다. 다음 시간에는 이 HTML을 다시 열고 이어쓰기 불러오기에서 JSON을 선택합니다.
  4. 끝나면 결과물 미리보기를 확인하고 제출용 문서 저장을 누릅니다. 저장된 HTML은 답안과 첨부 그림을 읽는 문서입니다.
  5. 저장한 문서를 다시 열어 내용을 확인한 뒤 교사가 지정한 과제함에 제출합니다. PDF 제출은 인쇄·PDF 저장에서 PDF 대상을 선택합니다.

입력은 자동 저장되지 않습니다. 창을 닫기 전에 저장하세요. AI 결과가 자동으로 들어오거나 교사에게 자동 제출되지는 않습니다.

교사가 안내한 활동 범위에 따라 작성합니다. 작성 누락 확인은 입력·첨부 여부를 점검하며, 답안이 옳은지를 자동으로 평가하지 않습니다.

직무 설명 · 먼저 읽기

백엔드 개발자는 화면 뒤에서 데이터 저장과 처리를 담당합니다. 이 활동의 가상 업무는 결제 처리 오류의 원인을 찾아 고치고, 재발을 점검하며 팀과 변경 내용을 공유하는 일입니다. Java·Spring 등은 기술 이름, 자격증은 학습·자격의 단서입니다. 이름을 안다는 사실만으로 실제 업무 능력을 확정하지 않습니다. 코딩 지식보다 이력서에서 무엇을 확인할 수 있는지를 판단하세요.

같은 AI 도구의 새 대화에 A·B를 각각 입력하고 실제 응답을 비교합니다. 두 자료에는 여러 차이가 있으므로 점수 차이를 한 표현의 효과로 단정하지 않습니다.

Gemini 접속·입력·응답 기록 방법
  1. Gemini 열기를 누르고 학교에서 허용한 Google 계정으로 로그인합니다. 오른쪽 위 계정 표시를 확인합니다.
  2. 왼쪽 메뉴에서 새 채팅을 엽니다. 메뉴가 접혀 있으면 먼저 메뉴 버튼을 누릅니다.
  3. 이 활동지의 요청문을 복사하여 Gemini 입력창에 붙여 넣습니다. 대괄호나 빈칸이 남아 있으면 활동에서 정한 내용으로 채웁니다.
  4. 응답을 받은 뒤, 원문 자료와 대조합니다. AI가 제시한 말이라는 이유만으로 근거로 인정하지 않습니다.
  5. 활동지로 돌아와 실제 응답과 도구명·사용 날짜를 남깁니다. 접속할 수 없으면 교사가 제공한 실제 응답을 사용하고 제공 자료임을 표시합니다.

Google 계정이 있어도 학교 설정과 연령에 따라 기능이 다를 수 있습니다. 로그인·이용 제한은 교사에게 확인하며, 수업은 유료 결제 없이 진행합니다.
